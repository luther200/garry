
# Garry

Garry is a Discord Bot.

## Installation:

```bash
> git clone https://github.com/luther200/garry
Cloning into 'garry'...

> cd garry/

> npm install
added 55 packages, and audited 56 packages in 2s

> npm run real (or dev)
/
```
